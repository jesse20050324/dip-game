三套游戏壳，关卡还是那两关。

官方 game/ 没动。这里只试「进关前后」像不像一款真正的轻解谜：开始 / 继续、选关、暂停、设置、关于。点进去可以玩第 1、第 2 关。

A · 书桌

一颗主按钮

标题很空。第一次写「开始」，有进度改成「继续」，全通了变成「选关」。选关、设置、关于是下面一排小字。暂停盖一层纸，不是返回键。

  • 静音在进关前
  • 锁关看得到、点了会晃
  • 设置里才能清进度，而且要确认
打开 A

B · 图鉴

两张照片当选关

封面像一本薄相册。选关是两张歪一点的照片：第一张、蘑菇。设置单独成页。通关盖一枚「修好了」。

  • 继续仍是封面最大的橙色按钮
  • 关于页写了声音来源
  • 暂停可以回图鉴或合上封面
打开 B

C · 一页纸

不换房间

标题、选关、对局、暂停都在同一张圆角纸上翻。继续会写「继续第 2 关」。选关是两个点：空心锁着，橙色是当前。

  • 暂停不另开暗房，只换这张纸的内容
  • 版本号只在封面上
  • Esc 也能暂停（桌面）
打开 C
