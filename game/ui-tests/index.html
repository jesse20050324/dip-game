UI tests · ten shells

十种外壳，关卡还是那两关。

同一套纸色、同一颗厚按钮。每一种是不同的地方，不是换一下排列。点进去能玩第 1、第 2 关。进度各自记着，不碰正式游戏。

01

掌机

开机键在机身上。暂停是屏幕里的系统菜单。设置在背面，不跟开始并排。

打开掌机

02

章节

封面、缎带、目录、扉页。有进度才露出书签，继续是从夹住的那一章翻开。

打开章节

03

集章

没有单独的选关页。卡片上的两枚章就是关卡，背面才是声音、清除和版权。

打开集章

04

馆签

不说开始，说走近。墙上已经挂着没看完的那一件，目录只负责换墙上的画。

打开馆签

05

抽屉

没进度是关着的抽屉。有进度时夹子探出来，抽它就继续。清除藏在抽屉里面。

打开抽屉

06

胶片

片门就是选关。声音和擦片是机身上的旋钮，永远不另开一页设置。

打开胶片

07

台历

只有今天能撕开。明天露一角但撕不掉。已经过的日子躺在废页堆里。

打开台历

08

信件

桌上只有最上面一封。拆开才是继续。第二封先封着，读过的另放一叠。

打开信件

09

展墙

第一次是进门，之后直接站在墙前。点画才靠近，暂停是退后半步。

打开展墙

10

样片

灯箱上两格。放大镜停在下一张。铅笔勾是进度，橡皮要按两次。

打开样片
