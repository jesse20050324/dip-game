# 游戏外壳研究（标题 / 菜单 / 暂停 / 选关）

> 2026-09-21。只研究「进关之前、出关之后」的壳：HOME / MENU / OPTIONS / PAUSE / LEVEL SELECT / SETTINGS / CREDITS / CONTINUE。不改关卡核心。
> 取样标准：暖、纸、像素、极简；教育或解谜；真正好用，不是同一套霓虹皮肤换皮。来源以 itch.io、独立移动解谜、轻量教育益智为主。故意不收街机霓虹、三消特效、直播 HUD。

## 四十多例（各写壳，不写玩法）

每条只记外壳怎么走：玩家从打开到进关、从关里出来、下次回来时看见什么。

1. **Monument Valley**（ustwo）— 标题几乎是一座纪念碑 + 一个开始。回来变成 Continue。选关是一条能走的谷，锁关看得到轮廓。暂停是薄幕，不是新页面。About 极短。
2. **Monument Valley 2** — 同一套：主按钮永远只有一个。通关后选关变成「回看」，不是再塞一个 Play。
3. **Mini Metro**（Dinosaur Polo Club / itch）— 标题即地图语言。进关 = 选一座城。Continue 记的是上一座城，不是抽象进度条。设置藏得深，进关后 UI 贴边、不抢线。
4. **Mini Motorways** — 同族：新游戏 / 继续分得很清。城市解锁是地图，不是列表。
5. **Baba Is You**（Hempuli / itch）— 世界图就是选关。暂停才出现 Options / 回地图。标题页很薄，世界图才是家。
6. **Patrick's Parabox** — 与 Baba 同族：选关是空间，不是按钮栅。锁关是空房间，不是弹窗。
7. **A Short Hike**（adamgryu / itch）— 标题「Press A」。设置、存档都在暂停里，不在标题堆按钮。第一次和第二次打开，标题几乎一样——因为只有一个存档槽，Continue 是默认。
8. **Unpacking**（Witch Beam）— 选关是搬家纸箱。已开箱 / 未开箱一眼可分。标题 Continue 指向没拆完的那一箱。
9. **A Little to the Left** — 标题有 Daily / 章节。设置独立成页（音量、重置）。暂停回到整理桌，不把玩家丢回系统桌面。
10. **Hidden Folks** — 标题就静音。场景选择像插画目录。没有「开始游戏」口号，点一幅画即进。
11. **Gorogoa** — 壳几乎消失。Continue 就是那一页还在。证明：壳可以少到「回到你停的那张纸」。
12. **DEVICE 6**（Simogo）— 整本书就是菜单。Credits 是版权页。设置少，因为阅读器不需要一堆开关。
13. **Year Walk**（Simogo）— 地图即选关。暂停不像游戏菜单，像合上地图。
14. **The Room**（Fireproof）— Continue 极强（房间没走完）。章节选择是次级。暂停 / 提示藏在齿轮里。
15. **Lumino City**（State of Play）— 纸模型城市当选关。锁关是没搭完的那栋。气质与本作成色最近的一类。
16. **Human Resource Machine**（Tomorrow Corporation）— 办公楼层 = 关卡。已通过的年份亮着。标题 Copy 很少，进度靠建筑。
17. **7 Billion Humans** — 同族：选关是空间化的职场，不是编号表。
18. **World of Goo** — 选关是群岛。锁关看得到、走不到。标题音乐 / 静音就在画面里。
19. **Little Inferno** — 目录当选关。Credits 做成产品说明书。
20. **Florence**（Mountains）— 章节是漫画格。Continue 翻到没读完的一格。没有 Pause 游戏菜单，只有「合上」。
21. **GRIS**（Nomada Studio）— 标题是画。Continue 默认。设置极少。通关不是奖杯页，是把画看完。
22. **Old Man's Journey** — 同族：风景标题，一个继续。
23. **Two Dots** — 手机益智教科书：Continue 最大；世界地图次之；设置是齿轮。锁关有明确的视觉差（空点 / 实点）。
24. **Threes** — 标题静音、怎么玩、分数。没有选关，因为只有一局——说明壳要跟体量匹配。
25. **Lara Croft GO** — 章节是立体缩略图。暂停 = 回章节 / 重开。Continue 记关卡不是记菜单。
26. **Hitman GO** — 同族：缩略图选关 + 锁。主按钮永远是继续当前合同。
27. **A Monster's Expedition**（Draknek / itch）— 地图漫游当选关。暂停很轻。回来直接站在岛上。
28. **Cosmic Express**（Draknek / itch）— 点阵选关。当前关略大。Pause 回选关，不是回系统。
29. **A Good Snowman Is Hard To Build** — 世界是 3D 选关。锁关是围栏，不是灰色按钮。
30. **Bonfire Peaks** — 同族：山体即进度。
31. **Snakebird** — 选关栅格 + 暂停重开。完成是安静的「鸟走了」，不是烟花。
32. **The Witness** — 几乎无菜单。暂停只有退出。证明重游戏可以没有选关页——但本作有关卡表，不能照抄「零菜单」。
33. **Viewfinder** — 暂停是相机菜单。设置少。Continue 进上一张照片。
34. **Papers, Please** — 下一天 = Continue。菜单是公文。Credits 像演职员表打印件。
35. **Return of the Obra Dinn** — 日志本即进度。没有传统选关栅。
36. **Kind Words**（popcannibal / itch）— 信纸 UI。设置是写信桌边上的小物件。Credits 像寄信人。
37. **Townscaper** — 几乎无壳。提醒：工具型可以没有 Continue；有关卡的游戏不行。
38. **Islanders** — 新岛 / 继续。设置一页。完成是分数摘要，很短。
39. **Dorfromantik** — 标题 Continue 最大。战役选关次之。设置含音量与重置。
40. **Chicory: A Colorful Tale** — 暂停是颜料盒。标题画风即游戏。
41. **Tunic** — 暂停即说明书。Credits / 设置在手册页里，不另开 App 风菜单。
42. **The Case of the Golden Idol** — 案卷目录当选关。Continue 是未结案。
43. **Storyteller** — 标题极简；选关是故事书脊。完成是合上这一页。
44. **FRAMED** — 胶片格当选关。暂停像剪辑台。
45. **My Little Diary**（Maria Hodor / itch）— 日记本即世界。工具在暂停/桌面，不在标题喊「开始」。
46. **Pack**（plasmastarfish / itch）— 打开就收拾。菜单极短。证明轻解谜可以「进门就是桌」。
47. **Opus Magnum**（Zachtronics）— 选关是羊皮卷目录。设置工程师化但仍然一页。
48. **Cocoon** — 标题一个开始。暂停极薄。完成不弹结算。
49. **Chants of Sennaar** — 日志 / 词典当进度。Continue 回到塔。
50. **The Talos Principle** — 星图选关。暂停哲学菜单，但仍是 Resume 第一。
51. **Alto’s Odyssey** — 标题静音、开始、次级商店。第一次没有 Continue。
52. **Tearaway** — 纸工艺选关。锁关是没裁完的纸。
53. **Picross / Nonograms Katana 类** — 选关栅 + 打开即静音入口。完成打勾。最「益智默认」。
54. **Donut County** — 标题一个 Play。设置在暂停。完成是安静的下一坑。
55. **Flower**（thatgamecompany）— 选关是花瓣。锁关未绽。没有 Pause 游戏感，只有风停。
56. **Pentiment**（Obsidian）— 壳是一本手稿。书签停在放下的那一页，没有另做关卡网格。
57. **Reigns**（Nerial）— 没有菜单页。一张卡就是全部界面，设置在卡背后。
58. **Assemble with Care**（ustwo）— 暖色修理台。要修的物件摆在台上，继续是没修完的那一件。

以上这些里，真正反复出现、且适合本作体量的不是「功能清单」，而是下面这些法。

## 从这些壳抽出的设计法

用在这次 `game/ui-tests/` 里的，共十二条。不是功能清单，是「玩家没提、但缺了会觉得不像游戏」的那些。

1. **主按钮永远只有一颗。** 标题上橙色的那个：第一次叫开始，有进度叫继续，全通了叫选关或再看。不要开始和继续并排抢。
2. **Continue 记住座位，不是记住菜单。** 点继续应进「没过的那一关」，不要打开选关让人再点一次。
3. **第一次和回来必须是两副面孔。** 没存档时不要出现继续；有存档时不要还写「开始游戏」装新的。
4. **静音在进关前。** 标题右上角就要有喇叭。手机玩家会在第一声之前把它按掉。
5. **暂停 ≠ 返回。** 返回是离开这关；暂停是盖一层纸：继续 / 选关 / 静音 / 回标题。对局里不要只放一个「退出」。
6. **锁关要看得见、点得着、进不去。** 空心、发灰、小锁。点了是轻晃 + 错声，不是没反应，也不是弹一篇教程。
7. **设置是一张卡片，不是控制台。** 音效开关 + 清除进度（二次确认）。不要画质、语言、键位、账号。
8. **Credits 是版权页，不是制作组滚屏。** 从标题能走到；写名字、声音来源、版本号。进关后不要看见它。
9. **通关是换口气，不是颁奖。** 两块颜色对齐、一句很短的话、一颗回主页。烟花和「YOU WIN」会把这作的纸感冲掉。
10. **版本号只在标题角落。** 对局、选关都不写 v0.x。
11. **对局 HUD 最多三件事。** 暂停、关号、喇叭。重置和确定属于关卡工具，不是壳。
12. **清进度必须两下。** 一下打开「真的清除？」，一下才清。误触在手机上太常见。

## 刻意没做的

- 账号、排行榜、每日挑战、商店、成就墙、过场 CG、加载条（本地瞬时）。
- 给关卡核心加字。壳可以用中英；格子里仍然无教学文案。
- 把 `prototype/chapter1/` 工坊改成带锁的正式页。

## 这次做的试玩站

官方 `game/` 不动。新壳在 `game/ui-tests/`。

第一轮只做了三套，仍是同一排功能换排版，设计者退回（见设计历程第 31 节）：

- **A 书桌** — 一颗主按钮，标题很空。
- **B 图鉴** — 选关是两张缩略图；设置独立成页。
- **C 一页纸** — 菜单和对局都在同一张卡片上翻。

第二轮改做十个**地方**。配色、厚按钮、前两关不变。每套换的是路径，不是皮肤。十二条法都还在用，另外加一条从退回里长出来的：**壳是一个地方，不是一张功能表。** 两套如果能靠同一排按钮换序互换，就不算两套。

| 套 | 地方 | 跟别的套不一样的路径 |
| --- | --- | --- |
| 01 掌机 | 机身 | 开机键在屏幕外。暂停是系统菜单。清除只在背面。 |
| 02 章节 | 薄书 | 封面 / 缎带 / 目录 / 扉页。继续＝从书签翻开。 |
| 03 集章 | 一张卡 | 没有选关页。章就是关。背面才是设置和版权。 |
| 04 馆签 | 墙 | 动词是「走近」。列表只换墙上的那一件，不直接进关。 |
| 05 抽屉 | 书桌 | 没进度是关着的。有进度夹子探出来，抽它即继续。 |
| 06 胶片 | 片门 | 选关就是拨片。声音和清除是旋钮，没有设置页。 |
| 07 台历 | 今天 | 只有今天能撕。明天是一角。过完的在废页堆。 |
| 08 信件 | 一叠信 | 永远只有最上面一封能拆。已读另放。 |
| 09 展墙 | 房间 | 第一次进门，之后人已经在墙前。暂停＝退后半步。 |
| 10 样片 | 灯箱 | 放大镜停在下一格。勾是进度。橡皮按两次。 |
