## 1. 一句话定位

**The Gray Workshop**（曾用名 Gray Mend / 灰度修理铺）：纯静态 HTML 2D 益智教育游戏，主题是数字图像处理。玩家在「左目标图 / 右操作图 / 底部灰度轴」的统一界面里，靠滑杆、边界把手和拖色块把一张灰度图「修」回彩色，全程无文字教学，判定逐像素比对。双击网页即玩，无构建、无依赖。

## 3. 核心机制（引擎，`game/app.js`）

界面三件套恒定：左 `targetCanvas`（目标/来件）、右 `workCanvas`（操作图）、底部 `axis-card`（灰度条 `grayBar` + 映射条 `mapBar` + 把手层）。

- **两种关卡模式**
  - `slider`：滑块 = 选中瓦片的灰度值，点瓦片选中、滑块跳到它的值。
  - `regions`：灰度轴被若干边界分成 N+1 段，映射条上给每段拖色；`movable` 时边界把手可拖，`adjustable` 时滑块同时可用（第 4 关）。
- **判定**：`checkWin()` 逐像素比对——slider 模式比灰度值（带 `tolerance`，默认 12），regions 模式比渲染颜色串。`judge: "button"` 需按确认键；`judge: "release"` 松手即判、错则弹回。
- **关卡配置项**：`prefill`（开局预涂某区间）、`lockedRegions`（禁涂区间，封捷径）、`initialSelect`（开局预选瓦片）、`prompt`（英文情景句）、`leftDisplay`（左侧来件图，≠判定对象）、`seamless`（64×64 关无格子缝渲染）。
- **答案揭晓**：有 `leftDisplay` 的关，做对后左侧自动切成修好图（`answerRevealed`），停 1.4s 再弹过关卡。
- **边界行程**：首尾把手可拖到轴两端（0/255），即「把某层灰度挤出轴外」= 删除元素（第 9 关核心操作）。
- **壳层**：主页（继续/再玩一遍变脸）→ 选关（缩略图卡片、未解锁灰锁）→ 对局（暂停罩层：继续/重开/选关/回主页）→ 过关卡（带原理句）→ 通关页。设置含静音 + 清进度（两步确认）；重置按钮也是两步确认（1.6s 内再按一次才清）。
- **存档**：`localStorage`，按 `body[data-scheme]` 隔离（`dip-lab-<scheme>-cleared`），静音全局一份。锁关逻辑：只解锁「已过最高关 +1」。
- **音效**：Kenney Interface Sounds（CC0），点按 1.00 / 落色 0.11 / 过关 0.09 / 错误 0.07 / 返回 0.04，无背景乐。

| 10 | 发黄旧信去墨渍 | 64×64 | 情景句 "Oh damn, the ink."；左侧是带渍来件，做对才揭晓干净信纸 |

64×64 四关（10–13）是「照片感」收束段：去掉格子缝渲染、左图从「标准答案」变成「坏掉的来件」，玩家用已学的阈值/映射修现实问题。通关原理句（英文方案）在第 1、2、3、10、13 关过关时给出，共五句。

## 5. 雾蓝方案（`game/blue/`，当前推荐门面）

- 主页整屏是程序绘制的灯塔海滩（天空淡云、海面波纹、沙滩颗粒），开局连同标题、按钮、图标一起被打成马赛克（`pixel-mask.js`），抓住滑条把手往右拖才逐块变清晰（`slider-boot.js`）。
- 滑条：只有抓住把手才动，填充条右端对齐把手圆心，松手过 0.9 补完并进游戏，否则回弹。
- 标题 The Gray Workshop 两行、圆润字体带白边，按钮组靠左不挡右侧灯塔。
- 全英文 UI（与中文深色方案共用同一份 `app.js`，靠 `data-scheme="blue"` 切语言与存档）。
