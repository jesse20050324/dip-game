# 游戏设计简报（初始阶段）

> 本文是本项目的设计事实来源。所有 agent 在讨论玩法、关卡、算法取舍或写代码前应先读本文。
> 状态：初始设计，未锁死。玩家笔记与筛选结论会随讨论更新。
> 设计决策的来龙去脉（含被推翻的方案）见 `docs/design-journey.md`，只增不删。

## 项目是什么

- 纯静态 **HTML 网页** 2D 教育 / 益智小游戏（2026-09-09 起弃用 Unity：HTML 做得快、效果好、双击即玩、分享零成本）。
- 入口分两套：`game/` 是正式游戏（开始界面 → 按关解锁）；`prototype/chapter1/` 是关卡工坊（十三关随便点，改关先在这里改，同意后再迁到 `game/`）。
- 背景领域：**数字图像处理（DIP）**，重点是让玩家在玩的过程中理解若干算法的**基础原理**，而不是背名词或看演示视频。
- 体量：**关卡总数目标约 15–20 关出头**（2026-09-09 定；含第一章已定的 7 小关）。早期「整段约 5 分钟」不再当硬上限——单关仍宜短，全作用小关凑满流水线，不必为卡 5 分钟砍章节。
- 阶段：第一章在做；后续章等第一章试玩后再排具体关卡表。为凑 15–20 关，优先把卷积 / 形态学 / RLE 拆成与第一章同粒度的小关，而不是加频域等旁支。

## 希望的游戏感觉

- 像素在游戏里是**看得见、摸得着的 2D 方块**（可带灰度数字）。
- 一种算法对应一条关卡线；一条线里可以有若干由易到难的小关，但都属于**同一件事**。
- 先让玩家亲手做**一小步**（例如算一个 3×3 邻域），再把同一规则放大成**对整张图操作**（例如卷积笔刷）。
- 小步必须能合成大步，有机衔接。明确避免做成「图像处理主题小游戏大全」。

## 设计约束（给后续实现用）

1. 优先做**一条修复 / 解码流水线**：每一步的输出是下一步的输入。
2. 不要为了覆盖教材而并列互不相关的玩法。
3. 可视化演示（只拖滑条看效果）可以当教学提示，但不能当关卡本身。
4. 大图像不要让玩家逐像素点击；教学用小网格手操，应用阶段改为「同一规则扫过 / 一次性应用到所有合法位置」。
5. 形态学、开闭运算不是新游戏，而是腐蚀 / 膨胀的组合关。
6. 频域、几何变换、特征提取默认**不进 5 分钟主线**；只有能接到同一张图的修复任务时才考虑插入。

## 设计者目前想到的玩法（原文意向，供对照）

这些是设计者已经能想象到交互的部分，**不是最终关卡表**。

- **二值化**：拖动阈值滑块显现黑白图（或二维码）。
- **多阈值颜色映射**：灰度轴上多个分割点 + 颜色块拖到正确区间，再把滑块拖到正确位置。
- **双阈值**：两个滑块把灰度分成三段（前景白 / 中间 / 背景黑）。
- **卷积（均值 / 中值 / 自定义核）**：左原图右结果图；先在 3×3 上手算中心像素，再把核变成笔刷扫大图。
- **腐蚀 / 膨胀**：结构元框住前景才为合法（绿框可点，红框不可）。顾虑是：图大了不能逐点点，做成笔刷又怕丢掉「咬一口」的感觉。开 / 闭运算是二者组合，问题相同。
- **频域滤波**：效果有趣，但暂时更像演示；能融合进主线再考虑。
- **几何变换**：和当前想象的内容较割裂，暂不作为主线。
- **特征提取**：设计者不熟，且不易做成关卡，暂不作为主线。
- **行程编码（RLE）**：用「一串同色被压成 计数×灰度」的方块表达压缩，再按编码拖回空白图还原。
- **RGB 三通道**：可以当一个环节，等核心算法玩法稳定后再加。

## 当前倾向的主线（筛选后建议，可推翻）

把整局收成**一件事**：修一张被噪声和灰度糊住的识别图（门禁码 / 字母 / 简单符号），直到能读出来并存档。

建议顺序（经典空域流水线，不是专题拼盘）：

1. 看懂像素网格（可选极短：RGB 合成灰度）
2. 邻域滤波（手算一格 → 笔刷扫图；用椒盐噪声逼出中值）
3. 阈值切开（同一条灰度轴，从 1 个滑块加到 2 个）
4. 形态学清理（小网格学会绿/红框 → 对整图应用；开运算 = 先腐蚀后膨胀）
5. 行程编码打包（把清理完的二值图存小，并可选还原校验）

### 可行性口诀（给后续讨论用）

- **A / 很适合关卡**：像素网格、RGB 合成灰度、单/双阈值、均值/中值/小核卷积、腐蚀、膨胀、开闭运算、RLE。直方图不要独立成关，画在阈值轴上。
- **B / 能做但易走题或超时**：多阈值伪彩、连通域填充、Hit-or-miss、Sobel 核、形态学梯度、四叉树压缩。最多当主线里的变体，不要新开专题。
- **C / 更像演示**：频域滤波、几何变换、直方图均衡、Otsu、自适应阈值、Huffman。默认不进主线（不要用它们来凑 15–20 关）。频域只有「图上就是周期条纹」时才考虑插一节频谱房间。
- **D / 不适合这个体量**：Canny 全流程、霍夫、Harris/SIFT/HOG、JPEG/小波、维纳/盲去卷积。

### 腐蚀大图

保留绿框/红框规则。教学用 ~12×12 大格要点几次；应用阶段改为预览所有合法位置后一次性应用（或扫过后按规则结算）。开闭运算不新增工具，只要求选对腐蚀/膨胀顺序。

定案或否决某算法时回写本节。

## 统一关卡骨架定案（2026-09-05 晚·二；2026-09-06 上午细化定稿）

### 全局骨架与规则

- 每关同一布局：左目标图（不动）、右操作图、底部灰度轴。目标永远是「让右边和左边一模一样」。
- 反馈：成功 = 右图边框绿闪 + 自动下一关；失败 = 红闪。**只有关 1 失败时滑块弹回原位；其余关失败保留现场，不重置。**
- 判定：正确解的右图必须与左图**逐像素一致**。答案颜色从目标图同一份调色板采样；正确解里禁止出现「未涂色/空色」格子。
- 无文字教学、无直方图、瓦片里不放数字（数字设计暂缓，要做需单独琢磨）。每关只出现该关决策用得到的元素。正式游戏的开始 / 结束界面可以有极少的符号按钮（▶ ✓ ↺），关卡核心仍无说明文字。
- 轴拆成两条（2026-09-06 定）：**上面灰度条**永远是灰度世界，意义从关 1 到关 6 不变（关 1-2 滑块从它取值，关 3 起出现分割线，关 4 起分割线变可拖把手）；**下面映射条**（关 3 起）每段显示该灰度区间被映射成的颜色，未涂色为斜线纹。把手是一条贯穿两条的竖线。色块托盘固定在映射条正下方，拖色块到区间 = 涂色，手势各关一致。
- 点格子 → 灰度条上冒出小标记，显示这格的深浅住在哪（关 2 起；关 1-2 里滑块本身就是标记），眼睛垂直往下看映射条即知这格变成什么颜色。
- 拖边界时，右图在灰度不同的瓦片缝隙上显示灰色轮廓线，松手消失（关 4 起）。

### 第一章 7 小关（定稿）

1. **对颜色**：左右各一个大方块，拖滑杆调右边深浅。无接近提示；松手即判定（容差约 ±12），对=绿闪过，错=红闪+滑块弹回。
2. **补瓦片**：5×5 简单图案，左右大部分一致、个别瓦片明显错。点任意瓦片（含本来对的）选中，滑杆复刻关 1 实时调。**开局预选一个错瓦片**（选中框暗示可点）。点确认按钮判定：错=红闪但保留已调结果。
3. **涂区间**（起承转合）：左=蒙德里安式大色块抽象画（自造，4 色），右=灰度版。轴上预分固定区间（边界在灰度空档），本关滑块不出现。拖色块到区间，对应灰度格子立即变色。教学点：轴上一段范围统一映射成一个颜色。
4. **调值+映射合体**：复刻蒙德里安《红、黄、蓝的构成》（20×20，含黑色线条，5 色）。两条轴同时可交互：上轴点选瓦片调灰度（关 2 玩法），下轴拖色映射（关 3 玩法，固定区间）。右下角小黄块的灰度被设成与背景白色相同——**在灰度图里直接隐形**（不是颜色错误，原因见 design-journey 第 10 节）。只调映射过不了关，必须先把它的灰度调进黄色区间。教学点：映射是灰度值的函数，同值必同色，想单独改色先改值。
5. **一个边界**：右=嵌套方块（每圈一灰度），左=实心方（浅奶油 / 深褐）。先把两色拖到边界两侧（涂反=反色图），再拖边界。实时预览保留，本关定位「顿悟关」、接受低难度；若试玩觉得太水，改为「确认才出结果 + 拖动时只显示灰色虚线阈值界限（松手消失）」。
6. **两个边界（雾·浮现）**：雾中月牙（金色月牙 + 奶白底；第一版两圆月牙）。三层灰：雾 36 / 月牙 112 / 背景 220。**颜色预填**（白 / 月色 / 白），无托盘。开局两刀在轴两端，三层落在中间月色段；把两刀收到月牙两侧，雾并入白、月牙落在月色，雾被去掉、月牙浮现。先试双阈值。第 7 关改用雾中爱心、自己涂色的「两刀」版，不再和第 6 关共用一张图。
7. **小风景**：左五色风景，右五灰度版。4 可拖边界 + 5 色块 = 关 3 + 关 5 合体，不引新机关。删光第一版的文字说明和对照表。
- 章末综合：风景+雾（6 灰度），边界+涂色一起上，不加新机关。

### 第一章扩展关（2026-09-09 晚定案，已实现）

8. **显现关（字母 A，现不占第 6 关）**：无左图、单边界、颜色预设让「A」浮现的那版，试玩觉得只是拖到一个好点，已从第 6 关撤下。第 6 关现为雾中月牙 + 预填色 + 双阈值。
9. **删太阳关**（关 7 之后）：左图 = 无太阳的风景。预设滑块位置已在正确处（⭐太阳涂色后可见，玩家才会发现「复刻不了」），颜色不预填。预期解 = 把天空/太阳边界拖出轴右端（255），太阳并入天空色。已知绕行解：把太阳区间直接涂成天空色——同为「并入背景」，可接受。教学点：删除 = 并入背景，关 6 顿悟的主动运用。
10. **发黄旧信**（照片感）：128×176 信纸，无缝。渍 36 / 墨 90 / 信头 150 / 纸 220。纸色预填且锁定。初始渍与墨同段。渍涂成纸色。签名从真实签名照片降采样成像素，不手绘笔形。⭐左=带渍彩信（不是答案），右=带渍灰度；一句英文情景 “Oh damn, the ink.”；做对后左图才换成干净信。左图渍色与字色极近但不同（渍略深），避免「同色却不同灰」违背已教原理。
11. **只要一个人**：64×64 半身像，无缝。上方不规则树枝 36 / 发 70 / 衣 115 / 肤 165 / 天 220。天、枝涂白。三色人先试。左=枝后彩照，情景 “Just her.”；做对后左图才换成白底人像。
12. **去掉日期戳**：64×64 海边红顶白塔（草图 1 原样：右岸沙嘴、白塔红锥顶、白灯室），无缝。窗 32 / 礁 55 / 沙 75 / 海 110 / 红顶 135 / 白塔 158 / 浪 170 / 天 185 / 戳 240。窗、礁、浪、天预填锁定；戳段开局预涂白色（可改）。沙/海/红/白/天在托盘。戳只盖在天上。把戳拖出轴右端并入天，或把戳段涂成天色。左=带戳彩景，情景 “Who watermarks this?”；做对后左图才换成无戳风景。
13. **老照片上色**：64×64 窗边人像，无缝。左图淡彩来件（不判定），判定对隐藏浓彩。五层：地 40 / 人 90 / 墙 140 / 天 190 / 领 230。初始边界乱放。情景 “A faded old photo.”；做对后左图才换成浓彩。
- **范围定案**：先只做第一章（灰度→阈值）并打通，卷积/形态学/RLE 等章节等第一章试玩后再排具体关卡表。全作目标 15–20 关出头，第一章占 7 关，其余大约 8–13 关留给后续章节（含小步/大步/组合，不是 4 个大关硬塞）。单关手感以试玩为准，不预先用总时长卡关数。

### 逻辑链（玩家视角）

位置=深浅（关1-2）→ 一段位置=一个颜色（关3）→ 值与映射合体：同值必同色（关4）→ 边界归我放（关5）→ 两个边界夹一层（关6）→ 边界+涂色综合（关7）。规则不变，控制权逐关交给玩家。

## 路线定案（2026-09-05 晚）

**定案：路子 B（算法本体的修复流水线）。** 定位：给没接触过或正在学数字图像处理的人，一关一关通关，领悟每个算法的核心点。

否决路子 A（机制化平台跳跃/格子版）的原因：A 只是把 B 的"图"换成"地图"，核心交互（调参数→验证）相同但花样更少；玩家玩明白后"这对应图像处理"的关联反而别扭；A 只能讲透一个性质，B 能让所有算法共享统一教学风格。

机制化头脑风暴的点子（见下节）存档为续作素材，不进本作。

### B 路线关卡结构

~~贯穿装置：识读机~~（2026-09-09 正式否决：没意义，不再讨论）。对错来自客观判定（逐像素比对），不来自"看着像"。防蒙混：正确参数必须从灰度值读出来。

主线是同一张识别图（门禁码/符号），多重病症，一关治一层，每关输出是下一关输入：

1. **关 1「灰蒙蒙」· 阈值**：按「统一关卡骨架定案」的 6 小关链执行（对颜色 → 一排格子 → 对数字 → 单切割点 → 双切割点 → 分段涂色）。教学点：灰度值、单/双阈值、分段映射。
2. **关 2「麻子脸」· 卷积（两拍）**：椒盐噪声。先给均值笔刷——扫完噪声抹开但机器仍读不出（注定的失败 = 教学）；小步：3×3 九宫格手算一格，亲眼看中值把 255 噪点扔掉；大步：中值笔刷扫全图。教学点：邻域、核、均值 vs 中值。
3. **关 3「毛边和断笔」· 形态学（三拍）**：小步 12×12 绿框/红框手点 → 大步"应用到所有合法位置" → 组合拍：又有毛刺又有断笔，选对腐蚀/膨胀顺序（开运算去毛刺、闭运算补断笔），选错机器"嘟"。
4. **关 4「打包带走」· RLE（结尾仪式，30–45 秒）**：看一行像素变成 计数×颜色 → 整图编码、文件大小往下掉 → 按编码把图打印回来校验无损。

番外（主线做完有剩余才做）：多阈值伪彩（老式色标传真，机器只认特定颜色编码——原型第三拍直接搬）；RGB 三通道（噪声只坏在一个通道，玩家诊断修哪个）。

候选新关卡（2026-09-09 晚讨论，详见 design-journey 第 17、18 节）：
- ~~显现关~~、~~删太阳关~~：已定案并实现，见上方「第一章扩展关」。
- **双阈值选择关**：多元素图只保留一个中间灰度层元素，其余映射成白背景（关 6 的镜像）。
- **RGB 三通道章节**（2026-09-09 结构定案，细节未锁死，详见 design-journey 第 18 节）：**合先于分**——合成线（叠白 → 浓度条调色 → 灰度图映射原料 → 合成原图 → 改错）先行，灰度化线（三色块灰度化 → 真图灰度化 → 闭环第一章识别图 → 改错）作为逆过程随后。经典系数只属于灰度化线。界面骨架：左目标 / 中结果 / 右原料，控件逐关生长。与第一章的关系说法：「伪彩映射（灰度→颜色是人为标签）vs 真彩合成（灰度是颜色原料）」。

不进本作：频域（"摩尔纹终关"是续作候选）、几何变换、特征提取、Otsu/自适应阈值、直方图均衡、JPEG/小波。

体量：上式「四段约 5 分钟」是早期估算，已由 **全作 15–20 关出头** 取代（见文首）。B 路线四段仍是章节主题，每段应拆成若干小关，不要按四个大关来做。名词后置：先会操作，再告诉玩家"修图的人叫它中值滤波"。

## 机制化方向（2026-09-05 头脑风暴，未定案）

起因：阈值原型被判定「游戏化不足」——拖滑块可以瞎蒙通关，本质是先文字教、再照做。
检验标准：**玩家完全不懂这个算法能不能通关？能 → 演示；不能 → 机制。**
新方向：算法的特性本身就是核心玩法（世界物理），理解 = 力量。候选机制：

- **量化/灰度级（目前最被看好）**：2D 平台跳跃，世界按 N 级灰度渲染。中间灰度的断桥调细才显形；反向地，中间灰度的尖刺调粗会融进背景消失。一个旋钮两种后果 + 位数预算。
- **阈值 = 实体化之眼**：灰度 > T 才是墙；双阈值 = 从杂物里只夹出特定灰度的物体。对错来自物理后果（掉下去），不是答题。
- **卷积核 = 配方**：玩家用数字池拼 3×3 核。边缘检测核 = 照妖镜看暗门；模糊核 = 抹钝尖刺；中值滤波克椒盐噪声（假方块/假敌人）让玩家自己发现。
- **形态学 = 体型工具**：腐蚀瘦身过缝/啃怪，膨胀变大够开关/当垫脚石；开运算去毛刺、闭运算补桥洞，同一关按顺序组合。
- **RLE = 负重**：连续同色压成「计数×颜色」才带得走；或当人肉解码器把编码打印成图。
- **RGB 通道 = 平行世界**：单通道视角切换看到不同平台（类 Outland 双色机制）。
- **频域（唯一保留点子）**：周期性激光墙在空域无解，进频域房间打掉频谱亮点 → 空域周期图案消失。

让瞎蒙失效的手法：答案必须从图/直方图里读出来；连续调节改离散档位；调节即世界即时物理改变（调错桥塌人掉）。

候选叙事外壳：玩家是修图机器人/暗房技师，每关一张坏照片，修图动作直接改变世界物理——天然一条流水线，不是小游戏合集。

注意：本节点子已随路线定案（见上节）归档为续作素材。阈值试验台的三拍引擎（N 切割点 + N+1 段颜色）直接作为 B 路线关 1 的核心组件继续使用。
