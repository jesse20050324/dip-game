# The Gray Workshop · 游戏描述 Outline

> 向不了解这个项目的人介绍：这是个什么样的游戏，从各个层面讲。
> 依据当前可玩版本（第一章 13 关完整可玩）。

---

## 1. 游戏概述

- 一款**像素益智解谜游戏**，题材是数字图像处理：玩家扮演「修图匠」，把坏掉的灰度图修复成彩色。
- 每关 1–3 分钟，全流程约 20–40 分钟；纯网页游戏，浏览器打开即玩，无需安装、无账号、无内购。
- 教育性藏在玩法里：通关过程就是一遍完整的图像灰度→颜色映射流程，玩家不知不觉学会「像素、灰度值、阈值、映射」这些概念，但全程没有一个教学文字。

## 2. 玩法层：玩家在做什么

- **固定界面**：左边一张目标图（要修成什么样），右边一张操作图（坏掉的），底部一条灰度轴。
- **三种操作**（随关卡逐个引入，不再增加）：
  1. **拖滑杆**——设定某个像素的灰度值（深浅）；
  2. **点格子**——选中图里的一块，看它的灰度落在轴上哪里；
  3. **拖色块 / 拖边界**——把颜色涂到灰度区间的映射条上；拖动分界线，改变"哪段灰度算一类"。
- **目标永远一句话（不说出口）：让右边变得和左边一样。** 做对逐像素判定通过，做错提示后可重试，无惩罚、无计时、无失败结局。
- 玩家自己会撞上图像处理的铁律，例如「同灰度必同颜色」——想让一块单独变色，必须先改它的灰度值。

## 3. 内容层：13 关的旅程（第一章）

- **教学前段（1–5 关）**：从 1×1 单色方块拖滑杆开始 → 5×5 蘑菇修瑕疵 → 抽象画按区间涂色 → 复刻蒙德里安名画（滑杆+映射并用）→ 拖一条边界切出方环。
- **机制中段（6–9 关）**：两条边界从两端夹出雾中月牙 → 雾中爱心自己涂色 → 山水风景四类景物五种颜色 → 「删掉太阳」：把边界拖出轴外，理解删除=并入背景。
- **应用后段（10–13 关，64×64「照片感」）**：界面变成真实照片场景，左侧不再是标准答案而是**坏掉的来件**，配一句英文情景：
  - "Oh damn, the ink."——去掉信纸上的墨渍
  - "Just her."——杂乱背景里只留下一个人
  - "Who watermarks this?"——去掉风景照上的水印
  - "A faded old photo."——把褪色老照片上回彩色
- 通关弹出一句原理说明（如「灰度是像素的亮度」），只在过关后出现。

## 4. 表现层：视觉

- **像素方块美学**：所有图像由程序生成的像素块拼成，无照片、无外部素材；低分辨率但构图讲究（名画复刻、风景、人物）。
- **两个界面方案**：
  - 深色方案：暗底卡片式界面；
  - **雾蓝方案（主打）**：主页是一整屏海滩灯塔像素画，开局整屏被打成马赛克，抓住滑条向右拖，画面逐块变清晰——「把图修清楚」这个核心动作在进游戏前就玩了一次。
- 全部界面无英文教学文字，交互引导靠界面状态本身（预选的格子、预涂的颜色、松手回弹）。

## 5. 表现层：听觉

- 轻量点按音效：按钮、落色、过关、错误、重置五类（Kenney CC0 素材）；
- 连续操作（拖滑条、拖边界）刻意不配音效；无背景音乐。

## 6. 结构层：游戏框架

- 主页（开始/继续）→ 选关（缩略图，未解锁灰色上锁）→ 对局 → 过关卡 → 通关页（Game Complete）。
- 暂停罩层、设置（音量开关、清进度二次确认）、进度自动保存在浏览器本地。
- 单线闯关制，过一关解锁下一关；已通关卡可回看重玩。

## 7. 技术层

- 纯 HTML/CSS/Canvas/原生 JS，零依赖、零构建；图像全部由代码程序生成。
- 支持鼠标与触屏；进度存 localStorage，换浏览器不互通。
- 关卡数据与渲染引擎分离，新关卡只是往配置表里加一条。

## 8. 规模与现状

- 后续章节（更多图像处理主题）尚未开工，全作目标 15–20 关出头。
