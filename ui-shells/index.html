UI / INTERACTION SHELLS

十版游戏外壳，原关卡网页不动。

这里只验收整体 UI 和交互：标题页、顺序解锁、选关、对局 HUD、暂停、通关。 中间的游戏画面故意留白。点确定会模拟通关并打开下一关。 A–E 是偏主题的对照版；F–J 按轻量教育解谜来做：简约、少装饰，关内不再写提示语。

共通规则：前一关通过才能进下一关。 已过关可回看，锁住的关进不去。 默认带着前 3 关已通的演示进度。 F–J 关内无字；标题页的 START / CONTINUE 可以有字。

对照 · A–E

A · 暗房

底片夹

把整局收成一间红灯暗房。关卡是一条胶卷：显影过的能回看，未曝光的格子抖一下，进不去。

  • 选关 = 胶卷画幅，不是圆点菜单
  • 通关像一次显影
  • 最贴后半段修照片的气质
打开 A

B · 街机

识图机

最像「游戏」的一版。柜体、闪烁 START、STAGE 格子。锁关直接报错，通关喊 STAGE CLEAR。

  • 选关 = 街机选关盘
  • 大颗街机键：重置 / 判定
  • 适合想要立刻有街机感的人
打开 B

C · 画廊

修复长廊

一条展览走廊。过关的画亮着，没到的画蒙着绒布、拦着绳子。进关像把画从墙上取下来修。

  • 选关 = 横向走动的画框
  • 对局像工作室里的两幅对照
  • 气质更静，偏独立解谜
打开 C

D · 控制室

流水线台

把「一条修复流水线」做成世界地图。节点一串连着，上游没提交，下游就是暗的。

  • 选关 = 管线节点图
  • 对局是控制台 HUD
  • 最能看见全作 15–20 关怎么往下接
打开 D

E · 手账

灯塔笔记

封面、地图、对开页。过关盖一枚蜡印，没走到的地点是空圈。像带着一本旅途笔记在修图。

  • 选关 = 手绘路线图
  • 对局是摊开的本子
  • 暖，但结构仍是正经游戏循环
打开 E

简约 · F–J

F · 浅纸

圆点纸台

最贴近现在本体：一张浅纸、一排圆点。锁住的点是空心，过了的点才实。关里不写一句话。

  • 选关 = 现在那种圆点，加上顺序锁
  • 按钮只留图标
  • 适合当「最小改动」对照
打开 F

G · 细线

发丝线

近白底、一根细线。选关是左边一列序号，右边是空。不靠颜色和装饰说话。

  • 冷一点，像印出来的纸
  • 几乎没有圆角和阴影
  • 锁关轻轻晃一下
打开 G

H · 点列

只有点

整页就是两排点。当前关略大，锁住的点空着。进关后头顶还是同一排点。

  • 最省字的选关
  • 进度一目了然
  • 像常见的独立解谜
打开 H

I · 对照

两幅

身份就是左右两块。选关收成一小格网格，进关后只剩对照和底下一排工具。

  • 画面占满，壳尽量瘦
  • 不讲故事房间
  • 和关卡骨架最贴
打开 I

J · 一页

单张纸

标题、选关、对局都在同一张纸上切换。没有第二个世界，轻得像一页网页。

  • 始终一个卡片轮廓
  • START 之后还是这张纸
  • 最接近「轻量网页游戏」
打开 J
